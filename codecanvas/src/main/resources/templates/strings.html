Strings

In Java, String is an object reference type representing an immutable sequence of characters. Mastering 0-based indexing, string methods, concatenation, and equality checking is essential for AP Computer Science A.

Core Concepts & Rules

Essential principles tested on the AP Computer Science A exam:

Zero-Based Indexing

The first character of a string is at index 0, and the last character is at index str.length() - 1.

Immutability

Strings cannot be modified after creation. Methods like toUpperCase() or substring() return a new String object rather than altering the existing one.

.equals() vs ==

Always use str1.equals(str2) to compare the text content of two strings. The == operator only checks if both variables point to the exact same memory location.

Key Methods

length() returns character count, substring(start, end) extracts a slice (end is exclusive), and indexOf(sub) locates a substring.

Example Program

This program demonstrates string length, substring slicing, searching with indexOf, and content comparison with .equals().

Complete Java Program

public class StringDemo {

    public static void main(String[] args) {

        String phrase = "AP CS Java";

        // Measuring length
        int len = phrase.length();

        // Substring extraction (index 0 up to 5 exclusive)
        String subject = phrase.substring(0, 5);

        // Substring from index 6 to the end
        String language = phrase.substring(6);

        // Finding the index of a character or substring
        int indexJava = phrase.indexOf("Java");

        // String comparison
        String target = "AP CS Java";
        boolean isMatch = phrase.equals(target);

        System.out.println("Original: " + phrase);
        System.out.println("Length: " + len);
        System.out.println("Subject: " + subject);
        System.out.println("Language: " + language);
        System.out.println("Index of 'Java': " + indexJava);
        System.out.println("Content matches: " + isMatch);
    }
}

Understanding the Program Structure

1. The Class Definition

public class StringDemo defines the enclosing blueprint. In Java, all runnable code resides within a class structure.

2. The Execution Entry Point

public static void main(String[] args) is invoked by the Java Virtual Machine (JVM) to start executing the program.

How Does Java Execute This Program?

Execution trace showing the sequential evaluation and memory state changes:

Step 1

The String object phrase is created in the string pool holding "AP CS Java".

Step 2

phrase.length() counts the 10 characters (including spaces) and stores 10 in len.

Step 3

phrase.substring(0, 5) extracts characters from index 0 through index 4, returning "AP CS".

Step 4

phrase.substring(6) extracts from index 6 to the end, returning "Java".

Step 5

phrase.indexOf("Java") locates the first appearance starting at index 6.

Step 6

phrase.equals(target) compares textual values character-by-character, evaluating to true.

Line-by-Line Explanation

Line 8 — length() method

int len = phrase.length();

Notice the parentheses: for Strings, length() is a method call, unlike arrays where length is a field.

Line 11 — substring(start, end)

String subject = phrase.substring(0, 5);

Extracts characters from start up to but NOT including end: characters at indices 0, 1, 2, 3, and 4.

Line 14 — substring(start)

String language = phrase.substring(6);

With a single argument, extracts from index 6 through the very end of the string.

Line 21 — .equals() comparison

boolean isMatch = phrase.equals(target);

Compares text values. Never use == to compare string contents on the AP exam.

AP Exam Tips & Common Traps

Keep these frequent multiple-choice traps in mind:

IndexOutOfBoundsException

Calling str.substring(0, str.length() + 1) or accessing index str.length() will crash with StringIndexOutOfBoundsException.

indexOf Return on Failure

If the substring is not found, indexOf() returns -1, not 0 or null.

compareTo() Method

a.compareTo(b) returns negative if a comes before b alphabetically, 0 if equal, and positive if a comes after b.
