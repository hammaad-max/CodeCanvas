Arrays

An array is a fixed-size container that stores multiple values of the same type. Array traversal, index manipulation, element replacement, and common standard algorithms (sum, average, minimum, maximum) are heavily tested on the AP CS A exam.

Core Concepts & Rules

Essential principles tested on the AP Computer Science A exam:

Fixed Size & Indexing

Arrays have a fixed size set when created. Indices range from 0 up to arr.length - 1. length is a field, not a method!

Default Values

Newly allocated arrays contain default values: 0 for numeric types, false for booleans, and null for object reference types.

Standard For Loop Traversal

Allows accessing and modifying elements using their index: for (int i = 0; i < arr.length; i++).

Enhanced For-Each Loop

Convenient for reading elements sequentially: for (int num : arr). Cannot be used to modify array elements or track index positions.

Example Program

This program demonstrates array creation, index traversal, calculating sum and average, and finding maximum values.

Complete Java Program

public class ArrayAlgorithms {

    public static void main(String[] args) {

        // Array declaration with an initializer list
        int[] scores = {85, 92, 78, 96, 88};

        // Algorithm 1: Calculate sum and average
        int sum = 0;
        for (int i = 0; i < scores.length; i++) {
            sum += scores[i];
        }
        double average = (double) sum / scores.length;

        // Algorithm 2: Find maximum value using enhanced for loop
        int max = scores[0];
        for (int score : scores) {
            if (score > max) {
                max = score;
            }
        }

        // Modifying an element
        scores[2] = 82; // replaces 78 with 82

        System.out.println("Array Length: " + scores.length);
        System.out.println("Total Sum: " + sum);
        System.out.println("Class Average: " + average);
        System.out.println("High Score: " + max);
        System.out.println("Updated Score at index 2: " + scores[2]);
    }
}

Understanding the Program Structure

1. The Class Definition

public class ArrayAlgorithms defines the enclosing blueprint. In Java, all runnable code resides within a class structure.

2. The Execution Entry Point

public static void main(String[] args) is invoked by the Java Virtual Machine (JVM) to start executing the program.

How Does Java Execute This Program?

Execution trace showing the sequential evaluation and memory state changes:

Step 1

Memory allocates a 5-element array initialized with values: [85, 92, 78, 96, 88].

Step 2

Standard loop visits each index 0 through 4, accumulating the sum: 85 + 92 + 78 + 96 + 88 = 439.

Step 3

Average is computed by casting (double) sum / scores.length = 439.0 / 5 = 87.8.

Step 4

Enhanced for loop iterates through each score; when encountering 96, max updates to 96.

Step 5

scores[2] = 82 changes the value at index 2 from 78 to 82.

Line-by-Line Explanation

Line 6 — Initializer list

int[] scores = {85, 92, 78, 96, 88};

Declares, allocates, and populates a 5-element array in one compact statement.

Line 10 — Loop boundary with .length

for (int i = 0; i < scores.length; i++)

Always use i < scores.length. Using <= will cause an ArrayIndexOutOfBoundsException.

Line 17 — Enhanced for-each loop

for (int score : scores)

Iterates through each element in order. In each pass, score takes on the value of the current element.

Line 24 — Array mutation

scores[2] = 82;

Accesses element at index 2 (the 3rd element) and assigns it the new value 82.

Notice how each output line correlates directly to each statement executed in the main method.

AP Exam Tips & Common Traps

Keep these frequent multiple-choice traps in mind:

.length Property vs .length()

Arrays use arr.length (no parentheses, it is an immutable field). Strings use str.length() (method call).

ArrayIndexOutOfBoundsException Trap

Valid indices for an array of size N are 0 to N - 1. Accessing arr[arr.length] is the #1 most common AP exam trap!

For-Each Cannot Modify Primitives

Writing for (int x : arr) { x = 0; } does NOT change the values in the array because x is merely a copy of the element.
