2D Arrays & Matrices

A two-dimensional array stores a grid of values in rows and columns. Matrix programs appear in almost every ISC practical paper: printing, diagonal sums, transpose, row and column sums, symmetric checks and sorting a matrix.

Core Concepts & Rules

Essential facts for working with matrices:

Declaring a 2D Array

int[][] m = new int[3][4]; creates 3 rows and 4 columns. m[i][j] is the element in row i, column j.

Dimensions

m.length is the number of rows; m[0].length is the number of columns in row 0.

Nested Loop Traversal

The outer loop moves through rows and the inner loop through columns, visiting every element in row-major order.

Diagonals

In an n × n matrix, the left (principal) diagonal is m[i][i] and the right diagonal is m[i][n - 1 - i].

Transpose

Rows become columns: t[j][i] = m[i][j]. An m × n matrix becomes n × m. A matrix equal to its transpose is symmetric.

Boundary Elements

An element is on the boundary if i == 0, i == rows - 1, j == 0 or j == cols - 1, a common ISC practical condition.

Example Program

This program prints a 3 × 3 matrix, adds both diagonals, builds its transpose and prints each row sum.

Complete Java Program

public class MatrixDemo {

    public static void main(String[] args) {

        int[][] m = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };
        int rows = m.length, cols = m[0].length;

        // Print the matrix row by row
        System.out.println("Matrix:");
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                System.out.print(m[i][j] + " ");
            }
            System.out.println();
        }

        // Sum of both diagonals
        int left = 0, right = 0;
        for (int i = 0; i < rows; i++) {
            left += m[i][i];
            right += m[i][cols - 1 - i];
        }
        System.out.println("Left diagonal sum = " + left);
        System.out.println("Right diagonal sum = " + right);

        // Transpose: rows become columns
        int[][] t = new int[cols][rows];
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                t[j][i] = m[i][j];
            }
        }
        System.out.println("Transpose first row: " + t[0][0] + " " + t[0][1] + " " + t[0][2]);

        // Row sums
        for (int i = 0; i < rows; i++) {
            int sum = 0;
            for (int j = 0; j < cols; j++) {
                sum += m[i][j];
            }
            System.out.println("Row " + i + " sum = " + sum);
        }
    }
}

Understanding the Program Structure

1. Matrix Initialiser

Each inner {...} is one row, so this creates a 3 × 3 matrix without needing new.

2. Reusable Dimensions

rows and cols are read from the array itself, so the loops still work if the matrix size changes.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

The nested print loops visit the matrix row by row, printing "1 2 3", "4 5 6" and "7 8 9".

Step 2

One loop adds the left diagonal (1 + 5 + 9 = 15) and the right diagonal (3 + 5 + 7 = 15) at the same time.

Step 3

The transpose copies each m[i][j] into t[j][i], so the first column of m (1, 4, 7) becomes the first row of t.

Step 4

For each row, sum is reset to 0 and the row's elements are added: 6, 15 and 24.

Line-by-Line Explanation

Line 10 — Rows and columns

int rows = m.length, cols = m[0].length;

m.length counts the inner arrays (rows); m[0].length counts the elements in the first row (columns).

Line 25 — Right diagonal index

right += m[i][cols - 1 - i];

As i goes 0, 1, 2, the column goes 2, 1, 0, which walks the diagonal from top-right to bottom-left.

Line 31 — Transposed size

int[][] t = new int[cols][rows];

The transpose swaps the dimensions; for a square matrix both are 3, but for a 2 × 3 matrix this would be 3 × 2.

Line 34 — Swapping indexes

t[j][i] = m[i][j];

Element in row i, column j moves to row j, column i.

Line 41 — Resetting a row total

int sum = 0;

Declaring sum inside the outer loop restarts it for every row; declaring it outside would give running totals instead.

Expected Console Output

Both diagonal sums share the centre element 5. In odd-sized square matrices, add the centre only once when a question asks for the sum of both diagonals together.

ISC Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

Row vs Column Order

m[i][j] is row first, then column. Swapping them in a non-square matrix causes ArrayIndexOutOfBoundsException.

Square Matrix Only

Diagonals and symmetry only make sense when rows equal columns. Check rows == cols before computing them.

Sorting a Matrix

A common practical trick: copy the matrix into a 1D array, sort it, then copy it back row by row.
