Strings & StringBuffer

ISC string programs work on whole sentences: splitting into words, changing case, counting frequencies and rearranging text. You also need to know why String is immutable and when the mutable StringBuffer is the better choice.

Core Concepts & Rules

Essential string-processing tools and rules:

Immutable String

A String object never changes. concat(), replace() and toUpperCase() return new Strings; you must assign the result to keep it.

Mutable StringBuffer

StringBuffer changes the same object in place with append(), insert(), reverse(), delete() and setCharAt(). It is efficient when text is built up in a loop.

Splitting into Words

sentence.split(" ") returns an array of words. StringTokenizer (from java.util) is an older way to do the same thing.

Character Frequency

Loop through the text with charAt(i) and count matches, or use an int[26] array indexed by ch - 'A' to count every letter at once.

Word Manipulation

Typical ISC tasks: capitalise the first letter of each word, reverse each word, sort words alphabetically with compareTo(), or find the longest word.

Useful Methods

trim() removes leading/trailing spaces, indexOf() and lastIndexOf() search, and String.valueOf(x) turns any value into text.

Example Program

This program capitalises every word of a sentence, counts words, edits a StringBuffer in place, demonstrates String immutability and counts the frequency of a letter.

Complete Java Program

public class StringOps {

    public static void main(String[] args) {

        String sentence = "java is fun to learn";

        // Capitalise the first letter of every word
        String[] words = sentence.split(" ");
        String result = "";
        for (String w : words) {
            result += Character.toUpperCase(w.charAt(0)) + w.substring(1) + " ";
        }
        System.out.println(result.trim());
        System.out.println("Words: " + words.length);

        // StringBuffer is mutable: the same object is changed
        StringBuffer sb = new StringBuffer("STACK");
        sb.reverse();
        System.out.println("Reversed: " + sb);
        sb.insert(0, ">> ");
        sb.append("!");
        System.out.println("After insert/append: " + sb);

        // String is immutable: concat() returns a NEW string
        String s = "Hi";
        s.concat(" there");
        System.out.println("s is still: " + s);

        // Frequency of a character
        String text = "MISSISSIPPI";
        int countS = 0;
        for (int i = 0; i < text.length(); i++) {
            if (text.charAt(i) == 'S') {
                countS++;
            }
        }
        System.out.println("S appears " + countS + " times");
    }
}

Understanding the Program Structure

1. Word-Level Processing

split(" ") breaks the sentence into an array, and a for-each loop rebuilds it word by word.

2. Character-Level Processing

The frequency count walks through the text one character at a time, the same pattern used for vowel counts and palindromes.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

split(" ") gives 5 words. For each word, the first character is upper-cased and joined to the rest (substring(1)) plus a space.

Step 2

trim() removes the final extra space before printing "Java Is Fun To Learn".

Step 3

sb.reverse() changes the buffer itself to "KCATS"; insert and append then extend the same object.

Step 4

s.concat(" there") builds a new String that is thrown away, so s is still "Hi". The loop then counts 4 S characters in "MISSISSIPPI".

Line-by-Line Explanation

Line 8 — Splitting a sentence

String[] words = sentence.split(" ");

Each space marks a boundary, so the result is {"java", "is", "fun", "to", "learn"}.

Line 11 — Capitalising a word

result += Character.toUpperCase(w.charAt(0)) + w.substring(1) + " ";

A char followed by + and a String gives a String, so the pieces join correctly.

Line 18 — Reversing in place

sb.reverse();

Unlike String methods, reverse() modifies the StringBuffer itself; no assignment is needed.

Line 26 — Immutability trap

s.concat(" there");

The new String "Hi there" is created but never stored, so it is lost. Writing s = s.concat(" there"); would keep it.

Line 33 — Counting a character

if (text.charAt(i) == 'S') {

Characters are compared with == because char is a primitive type (unlike Strings, which need equals()).

s is still: Hi

The StringBuffer lines show one object changing step by step, while the String s stays exactly as it was created.

ISC Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

💡 Assign String Results

A very common output question: s.toUpperCase(); on its own changes nothing. Only s = s.toUpperCase(); updates s.

💡 Extra Spaces

If the sentence has two spaces in a row, split(" ") produces an empty word, and charAt(0) on it throws an exception. Trim input or check the length first.

💡 StringBuffer equals()

StringBuffer does not compare contents with equals(). Convert with toString() first.
