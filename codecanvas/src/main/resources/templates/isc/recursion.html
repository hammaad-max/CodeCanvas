Recursion

A recursive method solves a problem by calling itself on a smaller version of the same problem. ISC asks you to write recursive methods and, very often, to trace them by hand and give the output.

Core Concepts & Rules

Essential ideas for writing and tracing recursion:

Base Case

The condition where the method returns an answer directly without calling itself. Without it, recursion never stops and causes StackOverflowError.

Recursive Case

The method calls itself with a smaller input (e.g. n - 1 or n / 10) so that the base case is eventually reached.

The Call Stack

Each call waits on the stack until the call it made returns. Results are then combined in reverse order as the calls "unwind".

Tracing

Write each call on its own line with its argument, go down to the base case, then work back up substituting returned values: fact(3) = 3 * fact(2) = 3 * 2 * fact(1) = 6.

Recursion vs Iteration

Any loop can be written recursively and vice versa. Recursion is often shorter and clearer; loops use less memory.

Classic Examples

Factorial, Fibonacci, sum or reverse of digits, GCD (Euclid), power, binary search, string reversal and palindrome checks.

Example Program

This program contains five classic recursive methods: factorial, Fibonacci, sum of digits, string reversal and GCD.

Complete Java Program

public class RecursionDemo {

    // n! = n * (n-1)!, with 1! = 1 as the base case
    static long factorial(int n) {
        if (n <= 1) {
            return 1;                    // base case stops the recursion
        }
        return n * factorial(n - 1);     // recursive case
    }

    // nth Fibonacci term: 0, 1, 1, 2, 3, 5, 8, 13, ...
    static int fib(int n) {
        if (n <= 1) {
            return n;
        }
        return fib(n - 1) + fib(n - 2);
    }

    // Sum of digits, e.g. 4721 -> 4 + 7 + 2 + 1
    static int digitSum(int n) {
        if (n == 0) {
            return 0;
        }
        return n % 10 + digitSum(n / 10);
    }

    // Reverse a string recursively
    static String reverse(String s) {
        if (s.length() <= 1) {
            return s;
        }
        return reverse(s.substring(1)) + s.charAt(0);
    }

    // GCD by Euclid's algorithm
    static int gcd(int a, int b) {
        return (b == 0) ? a : gcd(b, a % b);
    }

    public static void main(String[] args) {
        System.out.println("5! = " + factorial(5));
        System.out.println("fib(7) = " + fib(7));
        System.out.println("digitSum(4721) = " + digitSum(4721));
        System.out.println("reverse(\"ISC\") = " + reverse("ISC"));
        System.out.println("gcd(48, 18) = " + gcd(48, 18));
    }
}

Understanding the Program Structure

1. Each Method Has Two Parts

Every method starts with a base case (if ... return) and ends with a recursive call on a smaller input.

2. Called from main

main makes one call to each method; all the further calls happen inside the methods themselves.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

factorial(5) calls factorial(4), ... down to factorial(1), which returns 1. Unwinding gives 2, 6, 24 and finally 120.

Step 2

fib(7) branches into fib(6) + fib(5) and so on until fib(1) and fib(0); the results add up to 13.

Step 3

digitSum(4721) becomes 1 + digitSum(472) = 1 + 2 + 7 + 4 + 0 = 14.

Step 4

reverse("ISC") = reverse("SC") + 'I' = "CS" + "I" = "CSI". gcd(48, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0) = 6.

Line-by-Line Explanation

Line 5 — The base case

if (n <= 1) {

When n reaches 1 (or 0), the method returns 1 without recursing, which stops the chain of calls.

Line 8 — The recursive call

return n * factorial(n - 1);     // recursive case

The multiplication cannot happen until factorial(n - 1) returns, so each call waits on the stack.

Line 16 — Two recursive calls

return fib(n - 1) + fib(n - 2);

Each call makes two more, so the number of calls grows very quickly. This is why recursive Fibonacci is slow for large n.

Line 32 — Shrinking a String

return reverse(s.substring(1)) + s.charAt(0);

The rest of the string is reversed first, and the first character is attached at the end.

Line 37 — Recursion with the ternary operator

return (b == 0) ? a : gcd(b, a % b);

Euclid's rule: gcd(a, b) = gcd(b, a mod b), and gcd(a, 0) = a. The second argument shrinks every call.

Expected Console Output

5! = 120
fib(7) = 13
digitSum(4721) = 14
reverse("ISC") = CSI
gcd(48, 18) = 6

Each result is built while the calls return, not while they are made. Tracing on paper in two passes (down to the base case, then back up) avoids mistakes.

ISC Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

Missing or Wrong Base Case

If the base case can never be reached (for example n == 1 when called with 0), the method recurses forever and throws StackOverflowError.

Order of Printing

In a method that prints after its recursive call, output appears in reverse order. Check where the print statement is before tracing.

long for Factorials

Factorials grow fast: 13! no longer fits in an int. Use long for results above 12!.
