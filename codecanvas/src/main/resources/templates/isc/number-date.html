Number & Date Programs

The ISC practical paper almost always includes a number-based or date-based problem. These combine loops, methods and arrays: leap years, day numbers, base conversion and special numbers such as Kaprekar and Smith numbers.

Core Concepts & Rules

Essential rules and definitions for practical-paper problems:

Leap Year Rule

Divisible by 4 and not by 100, or divisible by 400. So 2024 and 2000 are leap years, but 1900 is not.

Day Number of a Date

Add the days of all earlier months to the day of the month, using an array of month lengths and 29 for February in leap years.

Decimal to Binary

Divide by 2 repeatedly; the remainders, read from last to first, form the binary number. 25 → 11001.

Kaprekar Number

Split the square into a right part with as many digits as the number and a left part; if they add up to the number it is Kaprekar: 45² = 2025 and 20 + 25 = 45.

Smith Number

A composite number whose digit sum equals the sum of the digits of its prime factors: 666 = 2 × 3 × 3 × 37, and 6 + 6 + 6 = 2 + 3 + 3 + (3 + 7) = 18.

Modular Approach

Write one small method per idea (isLeap, digitSum, toBinary) and combine them. Examiners award marks for well-defined methods.

Example Program

This program combines five small methods: a leap year test, a day-number calculator, a decimal-to-binary converter, and Kaprekar and Smith number checks.

Complete Java Program

public class NumberDate {

    static boolean isLeap(int y) {
        return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
    }

    // Day number (1-366) of a date within its year
    static int dayNumber(int day, int month, int year) {
        int[] days = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        if (isLeap(year)) {
            days[1] = 29;
        }
        int total = day;
        for (int i = 0; i < month - 1; i++) {
            total += days[i];
        }
        return total;
    }

    // Decimal to binary by repeated division by 2
    static String toBinary(int n) {
        String bin = "";
        while (n > 0) {
            bin = (n % 2) + bin;
            n /= 2;
        }
        return bin.isEmpty() ? "0" : bin;
    }

    // Kaprekar: 45 * 45 = 2025 and 20 + 25 = 45
    static boolean isKaprekar(int n) {
        int sq = n * n;
        int digits = String.valueOf(n).length();
        int divisor = (int) Math.pow(10, digits);
        return sq / divisor + sq % divisor == n;
    }

    static int digitSum(int n) {
        int s = 0;
        while (n > 0) {
            s += n % 10;
            n /= 10;
        }
        return s;
    }

    // Smith: composite, and digit sum equals digit sum of prime factors
    static boolean isSmith(int n) {
        int factorDigits = 0, factorCount = 0, m = n;
        for (int f = 2; f <= m; f++) {
            while (m % f == 0) {
                factorDigits += digitSum(f);
                factorCount++;
                m /= f;
            }
        }
        return factorCount > 1 && factorDigits == digitSum(n);
    }

    public static void main(String[] args) {
        System.out.println("2024 is leap: " + isLeap(2024) + ", 1900 is leap: " + isLeap(1900));
        System.out.println("1 March 2024 is day " + dayNumber(1, 3, 2024));
        System.out.println("25 in binary: " + toBinary(25));
        System.out.println("45 is Kaprekar: " + isKaprekar(45));
        System.out.println("666 is Smith: " + isSmith(666));
    }
}

Understanding the Program Structure

1. One Method per Task

Each method does one job and returns a value, so main reads like a list of questions and answers.

2. Methods Calling Methods

dayNumber uses isLeap, and isSmith uses digitSum, which is the modular style ISC expects.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

isLeap(2024): divisible by 4 and not by 100, so true. isLeap(1900): divisible by 100 but not by 400, so false.

Step 2

dayNumber(1, 3, 2024): February has 29 days in 2024, so 31 + 29 + 1 = 61.

Step 3

toBinary(25): remainders 1, 0, 0, 1, 1 are each placed in front, giving "11001". isKaprekar(45): 2025 / 100 + 2025 % 100 = 20 + 25 = 45.

Step 4

isSmith(666): the factor loop finds 2, 3, 3 and 37 (digit sums 2 + 3 + 3 + 10 = 18), which equals the digit sum of 666, and there is more than one factor.

Line-by-Line Explanation

Line 4 — Leap year condition

return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;

&& binds tighter than ||, but the brackets make the century rule clear to the reader.

Line 14 — Adding earlier months

for (int i = 0; i < month - 1; i++) {

For March (month 3) the loop adds only days[0] and days[1], January and February.

Line 24 — Building binary digits

bin = (n % 2) + bin;

Each new remainder goes on the left, because the last remainder is the most significant bit.

Line 35 — Splitting the square

return sq / divisor + sq % divisor == n;

With divisor = 100, 2025 / 100 is the left part (20) and 2025 % 100 the right part (25).

Line 51 — Prime factorisation

while (m % f == 0) {

Dividing out each factor as many times as it appears means only prime factors are ever found.

Expected Console Output

2024 is leap: true, 1900 is leap: false
1 March 2024 is day 61
25 in binary: 11001
45 is Kaprekar: true
666 is Smith: true

Every line is produced by calling a method and joining its return value into the output text, so each method can be tested on its own.

ISC Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

Century Years

Simply checking y % 4 == 0 wrongly treats 1900 as a leap year. Always apply the 100 and 400 rules.

Primes Are Not Smith

A prime number trivially matches its own digit sum, but Smith numbers must be composite. That is why the code checks factorCount > 1.

Validate Input

Practical papers award marks for rejecting invalid input, such as month 13 or day 31 in April, with a clear message.
