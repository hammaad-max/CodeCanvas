Classic Number Programs

Section B almost always includes a "special number" program. They all rely on the same few techniques: extracting digits with % 10 and / 10, counting factors, and comparing a computed value with the original number.

Core Concepts & Rules

The standard techniques and definitions examiners expect you to know:

Digit Extraction

n % 10 gives the last digit and n / 10 removes it. Repeating both inside while (n > 0) visits every digit from right to left.

Reverse and Palindrome

Build the reverse with rev = rev * 10 + digit. A palindrome number equals its reverse, e.g. 1221 or 545.

Armstrong Number

The sum of each digit raised to the power of the number of digits equals the number. For 3 digits: 153 = 1³ + 5³ + 3³.

Prime Number

Has exactly two factors: 1 and itself. Count the factors from 1 to n and check that the count is 2. Note that 1 is not prime.

Perfect Number

The sum of its proper factors (all factors except itself) equals the number: 28 = 1 + 2 + 4 + 7 + 14.

Other Board Favourites

Spy: digit sum = digit product (1124). Niven: divisible by its digit sum (126). Neon: digit sum of the square equals the number (9). Automorphic: the square ends with the number (25 → 625).

Example Program

This program tests four classic properties: palindrome, Armstrong, prime and perfect. Each one works on a copy of the number so that the original can still be printed.

Complete Java Program

public class NumberPrograms {

    public static void main(String[] args) {

        // 1. Reverse a number and test for palindrome
        int num = 1221, copy = num, rev = 0;
        while (copy > 0) {
            int digit = copy % 10;
            rev = rev * 10 + digit;
            copy = copy / 10;
        }
        System.out.println(num + (rev == num ? " is" : " is not") + " a palindrome");

        // 2. Armstrong number: sum of cubes of digits (3-digit number)
        int n = 153, temp = n, sumCubes = 0;
        while (temp > 0) {
            int d = temp % 10;
            sumCubes += d * d * d;
            temp /= 10;
        }
        System.out.println(n + (sumCubes == n ? " is" : " is not") + " an Armstrong number");

        // 3. Prime number: exactly two factors
        int p = 29, factors = 0;
        for (int i = 1; i <= p; i++) {
            if (p % i == 0) {
                factors++;
            }
        }
        System.out.println(p + (factors == 2 ? " is" : " is not") + " prime");

        // 4. Perfect number: sum of proper factors equals the number
        int q = 28, sumFactors = 0;
        for (int i = 1; i < q; i++) {
            if (q % i == 0) {
                sumFactors += i;
            }
        }
        System.out.println(q + (sumFactors == q ? " is" : " is not") + " a perfect number");
    }
}

Understanding the Program Structure

1. Digit-Based Checks

Palindrome and Armstrong both take digits off one at a time with % 10 and / 10 inside a while loop.

2. Factor-Based Checks

Prime and perfect both loop through possible divisors and test number % i == 0.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

Palindrome: digits of 1221 come off as 1, 2, 2, 1, building rev = 1, 12, 122, 1221. rev == num, so 1221 is a palindrome.

Step 2

Armstrong: digits of 153 are 3, 5, 1; their cubes are 27 + 125 + 1 = 153, equal to the number.

Step 3

Prime: of the numbers 1 to 29, only 1 and 29 divide 29 exactly, so factors is 2.

Step 4

Perfect: the factors of 28 below 28 are 1, 2, 4, 7 and 14, which add up to 28.

Line-by-Line Explanation

Line 6 — Keep a copy

int num = 1221, copy = num, rev = 0;

The loop destroys the number it works on (it ends at 0), so it works on copy. num is kept for the comparison and the output.

Line 9 — Building the reverse

rev = rev * 10 + digit;

Multiplying by 10 shifts the existing digits left one place, making room for the new digit on the right.

Line 18 — Cube of a digit

sumCubes += d * d * d;

d * d * d is an exact integer, whereas Math.pow(d, 3) returns a double and would need a cast.

Line 26 — Testing a factor

if (p % i == 0) {

A remainder of 0 means i divides p exactly, so it is a factor.

Line 34 — Proper factors only

for (int i = 1; i < q; i++) {

The loop stops before q, because a perfect number uses every factor except the number itself.

Expected Console Output

1221 is a palindrome
153 is an Armstrong number
29 is prime
28 is a perfect number

The ternary operator inside each println chooses between "is" and "is not", so the same line works whichever way the test turns out.

ICSE Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

Forgetting the Copy

Printing num after the loop without keeping a copy prints 0. Always copy the number before extracting digits.

Initial Values

Initialise sums and counters to 0 and products to 1. Starting a product at 0 makes every result 0.

Armstrong Power

For an n-digit number the power is n, not always 3: 1634 = 1⁴ + 6⁴ + 3⁴ + 4⁴. Count the digits first when the number of digits can vary.
