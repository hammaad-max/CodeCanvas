Arrays, Searching & Sorting

An array stores many values of the same type under one name. ICSE Section B frequently asks for linear search, binary search, bubble sort and selection sort, so knowing each algorithm step by step is essential.

Core Concepts & Rules

Essential array facts and the four standard algorithms:

Declaring and Indexing

int[] a = new int[5]; creates 5 elements, numbered 0 to 4, initialised to 0. a.length (no brackets) gives the size.

Linear Search

Check every element from the start until the target is found. Works on unsorted arrays; in the worst case it checks all n elements.

Binary Search

Works only on a sorted array. Compare with the middle element and discard half the array each time, so it is much faster on large arrays.

Bubble Sort

Repeatedly compare adjacent elements and swap them if they are in the wrong order. After each pass, the largest remaining element "bubbles" to the end.

Selection Sort

On each pass, find the smallest element in the unsorted part and swap it into the next position at the front. It does at most one swap per pass.

Double-Dimensional Arrays

int[][] m = new int[3][3]; stores a grid. m.length is the number of rows and m[0].length the number of columns. The left diagonal has row == col; the right diagonal has row + col == n - 1.

Example Program

This program searches an unsorted array with linear search, sorts it with bubble sort, and then finds a value with binary search.

Complete Java Program

public class ArrayDemo {

    public static void main(String[] args) {

        int[] arr = {42, 17, 8, 93, 25};

        // Linear search for 93
        int key = 93, pos = -1;
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == key) {
                pos = i;
                break;
            }
        }
        System.out.println("Linear search: " + key + " found at index " + pos);

        // Bubble sort (ascending)
        for (int i = 0; i < arr.length - 1; i++) {
            for (int j = 0; j < arr.length - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    int t = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = t;
                }
            }
        }
        System.out.print("Sorted: ");
        for (int x : arr) {
            System.out.print(x + " ");
        }
        System.out.println();

        // Binary search for 25 (array must be sorted)
        int low = 0, high = arr.length - 1, found = -1, target = 25;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (arr[mid] == target) {
                found = mid;
                break;
            } else if (arr[mid] < target) {
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }
        System.out.println("Binary search: " + target + " found at index " + found);
    }
}

Understanding the Program Structure

1. Array Initialiser

{42, 17, 8, 93, 25} creates and fills a 5-element array in one statement; the size comes from the number of values.

2. Three Algorithms in Sequence

Linear search runs on the original order, bubble sort rearranges the same array, and binary search then relies on that sorted order.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

Linear search compares 93 with 42, 17, 8 and then 93 at index 3; break stops the loop there.

Step 2

Bubble sort pass 1 moves 93 to the end, pass 2 moves 42 into place, and so on until the array is 8, 17, 25, 42, 93.

Step 3

Binary search: low = 0, high = 4, so mid = 2, and arr[2] is 25.

Step 4

The target is found on the very first comparison, so found is 2 and the loop ends.

Line-by-Line Explanation

Line 10 — Search with early exit

if (arr[i] == key) {

When the element matches, its index is saved and break leaves the loop. If nothing matches, pos stays -1, meaning "not found".

Line 19 — Shrinking inner loop

for (int j = 0; j < arr.length - 1 - i; j++) {

After i passes, the last i elements are already in place, so the inner loop can stop earlier. j + 1 must stay inside the array.

Line 21 — Swapping adjacent elements

int t = arr[j];

The temporary variable keeps arr[j] safe while it is overwritten, so no value is lost during the swap.

Line 36 — Middle index

int mid = (low + high) / 2;

Integer division finds the middle position of the part still being searched.

Line 41 — Discarding half

low = mid + 1;

If the middle element is smaller than the target, the target can only be to the right, so the left half is ignored.

Expected Console Output

Linear search: 93 found at index 3
Sorted: 8 17 25 42 93
Binary search: 25 found at index 2

The index found by linear search refers to the original order, while the binary search index refers to the sorted array. Sorting changes where each value is stored.

ICSE Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

💡 Binary Search Precondition

Binary search gives wrong answers on an unsorted array. If the question gives unsorted data, sort it first or use linear search.

💡 Off-by-One Errors

Valid indexes are 0 to length - 1. Accessing arr[arr.length] throws ArrayIndexOutOfBoundsException.

💡 length vs length()

Arrays use the property arr.length; Strings use the method s.length(). Mixing them up is a compile error.
