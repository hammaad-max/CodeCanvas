Character & String Handling

Text in Java is handled with the char type, the Character wrapper class and the String class. ICSE tests the output of String methods, character testing and conversion, and loop-based programs such as counting vowels and reversing words.

Core Concepts & Rules

Essential String and Character methods and rules:

Indexing

Characters are numbered from 0 to length() - 1. charAt(i) returns the character at index i.

Searching

indexOf(ch) returns the first position of a character or string, or -1 if it is not found. lastIndexOf() searches from the end.

Extracting

substring(start, end) returns the characters from start up to but not including end. substring(start) goes to the end.

Comparing

equals() compares contents (case matters); equalsIgnoreCase() ignores case. compareTo() returns 0 if equal, negative if the first comes earlier in dictionary order, positive if later.

Character Class

Character.isLetter(), isDigit(), isUpperCase(), isWhitespace() test a char; toUpperCase() and toLowerCase() convert it.

Strings are Immutable

Methods like toUpperCase() and replace() return a new String; the original is unchanged unless you assign the result back.

Example Program

This program demonstrates common String methods, then counts vowels and reverses a word with loops, and finishes with compareTo() and a Character test.

Complete Java Program

public class StringDemo {

    public static void main(String[] args) {

        String s = "Computer Applications";

        System.out.println("Length: " + s.length());
        System.out.println("charAt(3): " + s.charAt(3));
        System.out.println("indexOf('p'): " + s.indexOf('p'));
        System.out.println("substring(0, 8): " + s.substring(0, 8));
        System.out.println("toUpperCase(): " + s.toUpperCase());

        // Count vowels using a loop and Character methods
        int vowels = 0;
        for (int i = 0; i < s.length(); i++) {
            char ch = Character.toLowerCase(s.charAt(i));
            if ("aeiou".indexOf(ch) != -1) {
                vowels++;
            }
        }
        System.out.println("Vowels: " + vowels);

        // Reverse a word
        String word = "LEVEL", reversed = "";
        for (int i = word.length() - 1; i >= 0; i--) {
            reversed = reversed + word.charAt(i);
        }
        System.out.println(word + " reversed is " + reversed);
        System.out.println("Palindrome word? " + word.equals(reversed));

        System.out.println("compareTo: " + "apple".compareTo("banana"));
        System.out.println("isDigit('7'): " + Character.isDigit('7'));
    }
}

Understanding the Program Structure

1. Library Method Calls

The first block calls built-in String methods on the object s using the dot operator.

2. Character-by-Character Loops

The vowel counter and word reverser visit each index with a for loop and charAt(i), which is the pattern behind most ICSE string programs.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

"Computer Applications" has 21 characters (8 + 1 space + 12). Index 3 is 'p', which is also the first 'p', so indexOf gives 3.

Step 2

substring(0, 8) takes indexes 0 to 7, giving "Computer"; toUpperCase() returns a new upper-case copy.

Step 3

The vowel loop lower-cases each character and checks it against "aeiou": o, u, e, a, i, a, i, o give a count of 8.

Step 4

The reverse loop runs from index 4 down to 0, building "LEVEL", which equals the original, so the word is a palindrome. Finally 'a' - 'b' gives -1 for compareTo.

Line-by-Line Explanation

Line 7 — Length of a String

System.out.println("Length: " + s.length());

length() is a method for Strings (with brackets), unlike arr.length for arrays. Spaces count as characters.

Line 10 — Substring end index

System.out.println("substring(0, 8): " + s.substring(0, 8));

The end index 8 is excluded, so the result has 8 - 0 = 8 characters.

Line 17 — Testing for a vowel

if ("aeiou".indexOf(ch) != -1) {

A neat trick: if ch appears in "aeiou", indexOf returns its position; otherwise it returns -1.

Line 26 — Building a reversed String

reversed = reversed + word.charAt(i);

Joining a char to a String gives a new, longer String. The loop runs backwards, so characters are added from last to first.

Line 31 — Dictionary comparison

System.out.println("compareTo: " + "apple".compareTo("banana"));

compareTo subtracts the first differing characters: 'a' - 'b' is -1. A negative result means "apple" comes first.

Notice that s itself was never changed: toUpperCase() returned a new String, which is why the vowel count still sees the original mixed-case text.

ICSE Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

== vs equals()

== compares references, not text. Always use equals() (or equalsIgnoreCase()) to compare String contents.

Out of Range Index

s.charAt(s.length()) throws StringIndexOutOfBoundsException. The last valid index is length() - 1.

char Arithmetic

'A' + 1 is the int 66, but (char)('A' + 1) is 'B'. ASCII values: 'A' = 65, 'a' = 97, '0' = 48.
