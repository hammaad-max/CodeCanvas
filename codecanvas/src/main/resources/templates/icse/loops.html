Iterative Constructs & Loops

Loops repeat a block of statements. ICSE expects you to choose between for, while and do-while, trace how many times a loop runs, use break and continue, and write nested loops for patterns.

Core Concepts & Rules

Essential rules for writing and tracing loops:

for Loop

Best when the number of repetitions is known. for (init; test; update) keeps all three parts of the loop control in one line. It is an entry-controlled loop.

while Loop

Tests the condition before each pass (entry-controlled). Best when the number of repetitions is not known in advance, e.g. processing digits until the number becomes 0.

do-while Loop

Tests the condition after each pass (exit-controlled), so the body always runs at least once. Note the semicolon after while (condition);.

break and continue

break leaves the loop immediately. continue skips the rest of the current pass and jumps to the next iteration.

Nested Loops

A loop inside another loop. For each pass of the outer loop, the inner loop runs completely. Used for patterns and tables.

Infinite and Empty Loops

for (;;) or while (true) never stops on its own. A loop whose body is just ; is an empty (delay) loop.

Example Program

This program uses all three loop types and a nested loop: a sum with for, digit counting with while, a do-while whose condition is false from the start, and a number triangle.

Complete Java Program

public class LoopDemo {

    public static void main(String[] args) {

        // for loop: sum of first 5 natural numbers
        int sum = 0;
        for (int i = 1; i <= 5; i++) {
            sum += i;
        }
        System.out.println("Sum of 1 to 5 = " + sum);

        // while loop: count the digits of a number
        int n = 40721, digits = 0;
        while (n > 0) {
            digits++;
            n = n / 10;
        }
        System.out.println("Number of digits = " + digits);

        // do-while loop: runs at least once
        int k = 10;
        do {
            System.out.println("do-while ran with k = " + k);
            k++;
        } while (k < 5);

        // nested loops: a number triangle
        for (int row = 1; row <= 3; row++) {
            for (int col = 1; col <= row; col++) {
                System.out.print(col + " ");
            }
            System.out.println();
        }
    }
}

Understanding the Program Structure

1. Loop Control Variables

Each loop has a variable that changes every pass (i, n, k, row, col) and a condition that eventually becomes false.

2. Accumulators and Counters

sum collects a running total and digits counts passes. Both must be initialised (to 0) before the loop starts.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

The for loop runs with i = 1, 2, 3, 4, 5, adding each to sum: 1 + 2 + 3 + 4 + 5 = 15. It stops when i becomes 6.

Step 2

The while loop divides 40721 by 10 each pass (4072, 407, 40, 4, 0), counting 5 passes, so the number has 5 digits.

Step 3

The do-while body runs once with k = 10; then 10 < 5 is false, so it stops. A while loop would not have run at all.

Step 4

In the nested loop, row 1 prints one number, row 2 prints two and row 3 prints three; println() moves to a new line after each row.

Line-by-Line Explanation

Line 7 — The for loop header

for (int i = 1; i <= 5; i++) {

Initialisation runs once, the test runs before every pass, and the update runs after every pass. i exists only inside this loop.

Line 16 — Removing the last digit

n = n / 10;

Integer division by 10 drops the last digit (40721 becomes 4072). This is the standard way to walk through the digits of a number.

Line 25 — Exit-controlled test

} while (k < 5);

The condition is checked only after the body has run. The semicolon at the end is required.

Line 29 — Inner loop limit

for (int col = 1; col <= row; col++) {

The inner limit depends on the outer variable, which is what makes each row one number longer.

Line 30 — print vs println

System.out.print(col + " ");

print stays on the same line, so a whole row is printed side by side. The separate println() then ends the line.

Expected Console Output

Sum of 1 to 5 = 15
Number of digits = 5
do-while ran with k = 10
1
1 2
1 2 3

The do-while line proves that the body ran once even though its condition was false. Each triangle row ends with a trailing space from col + " ".

ICSE Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

Counting Iterations

for (i = 1; i <= n; i++) runs n times; for (i = 0; i < n; i++) also runs n times; i <= n starting at 0 runs n + 1 times.

Stray Semicolon

for (i = 1; i <= 5; i++); has an empty body; the block after it runs only once, after the loop finishes.

Entry vs Exit Controlled

A frequent theory question: for and while are entry-controlled; do-while is exit-controlled and runs at least once.
