Conditional Branching & Switch

Conditional statements let a program choose what to do. ICSE programs use if, if-else, the if-else-if ladder, the ternary operator and menu-driven switch statements with break and default.

Core Concepts & Rules

Essential rules for writing and tracing decision-making programs:

if and if-else

An if runs its block only when the condition is true. An else block runs when it is false. Conditions must be boolean expressions.

if-else-if Ladder

Conditions are tested from top to bottom; the first true one runs and the rest are skipped. A final else catches every remaining case.

switch-case

Compares one value (int, char, String, etc.) against constant case labels. It is ideal for menu-driven programs.

break and Fall-Through

Without break, execution "falls through" into the next case. Fall-through is sometimes used on purpose to share code between cases.

default

Runs when no case matches. It is optional and can appear anywhere, but is usually written last.

Logical Operators

&& (AND), || (OR) and ! (NOT) combine conditions. && and || short-circuit: the right side is skipped when the left side already decides the result.

Example Program

This program assigns a grade with an if-else-if ladder, runs a menu choice with switch, uses the ternary operator, and shows intentional fall-through.

Complete Java Program

public class GradeAndMenu {

    public static void main(String[] args) {

        int marks = 78;
        char grade;

        if (marks >= 90) {
            grade = 'A';
        } else if (marks >= 75) {
            grade = 'B';
        } else if (marks >= 60) {
            grade = 'C';
        } else {
            grade = 'D';
        }
        System.out.println("Marks: " + marks + "  Grade: " + grade);

        int choice = 2;
        switch (choice) {
            case 1:
                System.out.println("Area of circle selected");
                break;
            case 2:
                System.out.println("Area of square selected");
                break;
            default:
                System.out.println("Invalid choice");
        }

        String result = (marks >= 40) ? "Pass" : "Fail";
        System.out.println("Result: " + result);

        int day = 6;
        switch (day) {
            case 6:
            case 7:
                System.out.println("Weekend");
                break;
            default:
                System.out.println("Weekday");
        }
    }
}

Understanding the Program Structure

1. Decision with Ranges

The if-else-if ladder handles ranges of marks, which switch cannot do because case labels must be single constant values.

2. Decision with Exact Values

The two switch statements handle exact values (a menu choice and a day number), which is where switch is clearest.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

marks = 78: 78 >= 90 is false, 78 >= 75 is true, so grade becomes 'B' and the remaining conditions are never tested.

Step 2

switch (choice) jumps straight to case 2, prints its message and break leaves the switch.

Step 3

The ternary operator checks 78 >= 40, which is true, so result is "Pass".

Step 4

day = 6 matches case 6, which is empty, so execution falls through into case 7, prints "Weekend" and stops at break.

Line-by-Line Explanation

Line 8 — First condition tested

if (marks >= 90) {

Relational operators produce a boolean. Because 78 is not at least 90, Java moves on to the next else if.

Line 10 — The matching branch

} else if (marks >= 75) {

This is the first true condition, so its block runs. Even though marks >= 60 is also true, that branch is skipped.

Line 24 — Case with break

case 2:

When choice is 2, execution starts here. The break after the print statement stops it from running the default code too.

Line 31 — Ternary in place of if-else

String result = (marks >= 40) ? "Pass" : "Fail";

A one-line choice between two values. Both possible values must be compatible with the variable type (here, String).

Line 36 — Intentional fall-through

case 6:

An empty case with no break falls into the next one, so days 6 and 7 share the same code.

Expected Console Output

Marks: 78  Grade: B
Area of square selected
Result: Pass
Weekend

Only one message is printed per decision. If the break in case 2 were removed, "Invalid choice" would also be printed.

ICSE Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

Missing break

A favourite output question: a switch without break keeps running every following case, including default.

Order of the Ladder

Write range conditions from the most restrictive to the least. Testing marks >= 60 first would give 95 marks a C.

switch Limits

Case labels must be constants and unique. switch cannot test boolean, long, double or ranges like marks > 90.
