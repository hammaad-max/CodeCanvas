Operators & Expressions

Operators combine values into expressions. ICSE Section A regularly tests prefix and postfix increments, integer division, the remainder operator, type casting, the ternary operator and the return types of Math library methods.

Core Concepts & Rules

Essential rules for predicting the value of any expression:

Prefix vs Postfix

++a increments first and then uses the new value. a++ uses the current value first and increments afterwards.

Integer Division

When both operands are int, / discards the fraction: 17 / 5 is 3. The remainder operator % gives what is left: 17 % 5 is 2.

Type Conversion

Implicit (widening, automatic): int to double. Explicit (narrowing, a cast): (int) 7.9 gives 7 because the decimal part is truncated.

Ternary Operator

condition ? value1 : value2 is a compact if-else that produces a value. It is the only operator with three operands.

Operator Precedence

Unary (++, --, !) first, then * / %, then + -, then relational, then &&, then ||, then ?:, and assignment last.

Math Library

Math.pow(), Math.sqrt(), Math.ceil() and Math.floor() return double. Math.round(double) returns long. Math.abs() keeps the argument's type.

Example Program

This program evaluates a mixed prefix/postfix expression, integer and real division, the ternary operator and several Math methods.

Complete Java Program

public class OperatorDemo {

    public static void main(String[] args) {

        int a = 5;
        int b = a++ + ++a;      // 5 + 7
        System.out.println("a = " + a + ", b = " + b);

        int x = 17, y = 5;
        System.out.println("x / y = " + (x / y));
        System.out.println("x % y = " + (x % y));

        double avg = (double) x / y;
        System.out.println("avg = " + avg);

        int big = (x > y) ? x : y;
        System.out.println("bigger = " + big);

        System.out.println("pow = " + Math.pow(2, 5));
        System.out.println("sqrt = " + Math.sqrt(81));
        System.out.println("round = " + Math.round(-2.5));
        System.out.println("ceil = " + Math.ceil(4.1) + ", floor = " + Math.floor(4.9));
    }
}

Understanding the Program Structure

1. The Class Definition

public class OperatorDemo is the container for the program; all Java code must be inside a class.

2. The main Method

Statements in main run from top to bottom. Every expression is fully evaluated before its result is printed.

How Does Java Execute This Program?

Execution trace showing the order in which statements run and how values change:

Step 1

a++ gives 5 and makes a 6; then ++a makes a 7 and gives 7. So b = 5 + 7 = 12.

Step 2

17 / 5 is integer division (3) and 17 % 5 is the remainder (2).

Step 3

(double) x turns 17 into 17.0 before dividing, so avg is 3.4. The ternary picks 17 because 17 > 5 is true.

Step 4

The Math calls run: pow and sqrt return doubles (32.0, 9.0), round(-2.5) rounds up to -2, ceil gives 5.0 and floor gives 4.0.

Line-by-Line Explanation

Line 6 — Prefix and postfix together

int b = a++ + ++a;      // 5 + 7

Java evaluates operands left to right. The postfix part supplies 5 then increments; the prefix part increments again (to 7) and supplies 7. Final a is 7.

Line 10 — Integer division

System.out.println("x / y = " + (x / y));

The brackets matter: without them, "x / y = " + x would join text first. Both operands are int, so the result is 3, not 3.4.

Line 13 — Explicit type cast

double avg = (double) x / y;

The cast applies to x only, but one double operand is enough to make the whole division real: 17.0 / 5 = 3.4.

Line 16 — Ternary operator

int big = (x > y) ? x : y;

If the condition is true the expression takes the value after ?, otherwise the value after :.

Line 21 — Math.round with a negative half

System.out.println("round = " + Math.round(-2.5));

Math.round(x) works like Math.floor(x + 0.5), so -2.5 becomes -2 (not -3). The result type is long, so no decimal point is printed.

Expected Console Output

a = 7, b = 12
x / y = 3
x % y = 2
avg = 3.4
bigger = 17
pow = 32.0
sqrt = 9.0
round = -2
ceil = 5.0, floor = 4.0

Look at which results have a decimal point: every double value (including pow, sqrt, ceil and floor) prints with .0, while int and long results do not.

ICSE Board Exam Tips & Common Traps

Keep these frequent exam traps in mind:

💡 Cast Position Trap

(double)(17 / 5) is 3.0, because the integer division happens first. Cast an operand, not the result, to keep the fraction.

💡 Math Return Types

Writing int p = Math.pow(2, 3); is a compile error. You need int p = (int) Math.pow(2, 3);.

💡 Shorthand Assignment

a += 2.5 compiles even when a is an int (it includes an automatic cast), but a = a + 2.5 does not.
