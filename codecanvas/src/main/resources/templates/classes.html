Classes & Objects

Java is an object-oriented programming language. A class is a blueprint, and an object is an instance of that blueprint. Encapsulation, constructors, accessor (getter) methods, and mutator (setter) methods form the core of AP CS A.

Core Concepts & Rules

Essential principles tested on the AP Computer Science A exam:

Encapsulation & Private Fields

Instance variables are declared private so they cannot be altered directly from outside the class, keeping object state secure.

Constructors

Special methods that initialize newly created objects. A constructor has the exact same name as the class and has NO return type (not even void).

The 'this' Keyword

A reference to the current object. Commonly used in constructors to differentiate instance variables from parameters with the same name: this.name = name;.

Accessors & Mutators

Accessors (getters) return private field values. Mutators (setters) change private field values, allowing validation of incoming data.

Example Program

This program demonstrates class definition, private encapsulation, constructor initialization, and getter/setter methods.

Complete Java Program

public class Student {

    // Private instance variables (Encapsulation)
    private String name;
    private int grade;

    // Constructor to initialize state
    public Student(String name, int grade) {
        this.name = name;
        this.grade = grade;
    }

    // Accessor (Getter) method
    public String getName() {
        return name;
    }

    // Mutator (Setter) method with validation
    public void setGrade(int newGrade) {
        if (newGrade >= 9 && newGrade <= 12) {
            this.grade = newGrade;
        }
    }

    public int getGrade() {
        return grade;
    }

    public static void main(String[] args) {

        // Instantiating objects using 'new'
        Student s1 = new Student("Maya", 10);

        System.out.println("Student Name: " + s1.getName());
        System.out.println("Initial Grade: " + s1.getGrade());

        // Update grade via mutator
        s1.setGrade(11);
        System.out.println("Updated Grade: " + s1.getGrade());
    }
}

Understanding the Program Structure

1. The Class Definition

public class Student defines the enclosing blueprint. In Java, all runnable code resides within a class structure.

2. The Execution Entry Point

public static void main(String[] args) is invoked by the Java Virtual Machine (JVM) to start executing the program.

How Does Java Execute This Program?

Execution trace showing the sequential evaluation and memory state changes:

Step 1

The JVM loads the Student class and executes the main method.

Step 2

new Student("Maya", 10) allocates memory on the heap for a new object.

Step 3

The constructor executes: this.name = "Maya" and this.grade = 10 initialize the instance variables.

Step 4

s1.getName() and s1.getGrade() access the private fields through public getter methods.

Step 5

s1.setGrade(11) validates that 11 is between 9 and 12, then safely mutates the grade field.

Line-by-Line Explanation

Line 4–5 — Private instance variables

Declaring fields private ensures outside code cannot corrupt an object's state.

Line 8 — Constructor definition

Notice no return type. The constructor initializes the object when created with new.

Line 9 — 'this' reference

this.name refers to the instance variable, while name refers to the incoming parameter.

Line 20 — Mutator with validation

Mutators allow defensive programming by verifying inputs before modifying state.

AP Exam Tips & Common Traps

Keep these frequent multiple-choice traps in mind:

💡 Default Constructor Trap

If you write ANY custom constructor in a class, Java will NOT provide the default no-argument constructor automatically.

💡 NullPointerException

Calling an instance method on a variable that holds null (e.g. s1.getName() when s1 == null) crashes with NullPointerException.

💡 toString() Method

Overriding public String toString() allows printing an object directly with System.out.println(obj) instead of printing its memory address.
