Expressions & Assignment

Expressions combine values, variables, and operators to produce new values. Understanding operator precedence, integer division, the modulus operator, and type casting is fundamental to scoring well on AP CS A.

Core Concepts & Rules

Essential principles tested on the AP Computer Science A exam:

Arithmetic Operators

Java provides + (addition), - (subtraction), * (multiplication), / (division), and % (modulus/remainder).

Integer Division Truncation

When dividing two integers (int / int), Java discards the decimal fraction entirely. For example, 7 / 2 evaluates to 3, not 3.5.

The Modulus Operator (%)

The % operator yields the integer remainder after division. For example, 17 % 5 is 2 because 5 goes into 17 three times with 2 left over.

Type Casting

Cast an int to a double using (double) x to force floating-point division: (double) 7 / 2 evaluates to 3.5.

Example Program

This program demonstrates integer division, floating point type casting, remainder evaluation via modulus, and compound assignment.

Complete Java Program

public class ArithmeticDemo {

    public static void main(String[] args) {

        int totalScore = 95;
        int numTests = 4;

        // Integer division (truncates fraction)
        int intAvg = totalScore / numTests;

        // Floating-point division using explicit casting
        double realAvg = (double) totalScore / numTests;

        // Modulus (remainder)
        int remainder = totalScore % numTests;

        // Compound assignment
        int bonus = 10;
        bonus += 5; // equivalent to bonus = bonus + 5

        System.out.println("Integer Average: " + intAvg);
        System.out.println("Real Average: " + realAvg);
        System.out.println("Remainder: " + remainder);
        System.out.println("Final Bonus: " + bonus);
    }
}

Understanding the Program Structure

1. The Class Definition

public class ArithmeticDemo defines the enclosing blueprint. In Java, all runnable code resides within a class structure.

2. The Execution Entry Point

public static void main(String[] args) is invoked by the Java Virtual Machine (JVM) to start executing the program.

How Does Java Execute This Program?

Execution trace showing the sequential evaluation and memory state changes:

Step 1

JVM initializes main method and allocates memory for totalScore (95) and numTests (4).

Step 2

Java evaluates 95 / 4. Since both operands are ints, the result is truncated to 23 and stored in intAvg.

Step 3

(double) totalScore converts 95 to 95.0. 95.0 / 4 performs double division, storing 23.75 in realAvg.

Step 4

95 % 4 calculates the remainder (3), and bonus += 5 increases bonus from 10 to 15 before printing.

Line-by-Line Explanation

Line 8 — Integer Division

int intAvg = totalScore / numTests;

Because both totalScore and numTests are integers, integer division drops everything after the decimal.

Line 11 — Explicit Cast to double

double realAvg = (double) totalScore / numTests;

Casting totalScore to double forces floating-point arithmetic so the fractional portion is preserved.

Line 14 — Modulus Operator

int remainder = totalScore % numTests;

The remainder operator gives 3, since 4 × 23 = 92, and 95 - 92 = 3.

Line 17–18 — Compound Assignment

int bonus = 10; bonus += 5;

+= adds the right operand to the variable and assigns the result back to that variable.

Expected Console Output

Integer Average: 23
Real Average: 23.75
Remainder: 3
Final Bonus: 15

Notice how each output line correlates directly to each statement executed in the main method.

AP Exam Tips & Common Traps

Keep these frequent multiple-choice traps in mind:

💡 Casting Precedence Trap

(double)(totalScore / numTests) evaluates integer division FIRST (yielding 23), then casts to 23.0! Always cast one operand before dividing.

💡 Negative Modulus

In Java, the sign of a % b matches the sign of a (the dividend). For example, -7 % 3 is -1.

💡 Even/Odd Checks

A standard AP CS check: n % 2 == 0 tests if a number is even, and n % 2 != 0 tests if it is odd.
