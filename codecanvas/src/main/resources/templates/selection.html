Selection

Selection statements allow programs to make decisions and execute different blocks of code based on boolean conditions. Mastery of if, else-if, nested branches, relational operators, and short-circuit evaluation is essential.

Core Concepts & Rules

Essential principles tested on the AP Computer Science A exam:

Relational Operators

== (equals), != (not equal), < (less than), <= (less than or equal), > (greater than), >= (greater than or equal).

Logical Operators

&& (AND — true only if both are true), || (OR — true if at least one is true), and ! (NOT — inverts boolean value).

Short-Circuit Evaluation

In A && B, if A is false, B is never evaluated. In A || B, if A is true, B is never evaluated.

De Morgan's Laws

!(A && B) is equivalent to !A || !B. !(A || B) is equivalent to !A && !B.

Example Program

This program demonstrates multi-branch conditional logic using if-else if-else and compound boolean logic.

Complete Java Program

public class GradeClassifier {

    public static void main(String[] args) {

        int score = 88;
        boolean hasCompletedHonors = true;

        char letterGrade;

        // Multi-way selection with if-else if-else
        if (score >= 90) {
            letterGrade = 'A';
        } else if (score >= 80) {
            letterGrade = 'B';
        } else if (score >= 70) {
            letterGrade = 'C';
        } else {
            letterGrade = 'F';
        }

        // Logical AND + boolean condition
        boolean isDeanList = (letterGrade == 'A' || letterGrade == 'B') && hasCompletedHonors;

        System.out.println("Score: " + score);
        System.out.println("Assigned Grade: " + letterGrade);
        System.out.println("Dean's List Eligible: " + isDeanList);
    }
}

Understanding the Program Structure

1. The Class Definition

public class GradeClassifier defines the enclosing blueprint. In Java, all runnable code resides within a class structure.

2. The Execution Entry Point

public static void main(String[] args) is invoked by the Java Virtual Machine (JVM) to start executing the program.

How Does Java Execute This Program?

Execution trace showing the sequential evaluation and memory state changes:

Step 1

Variables score = 88 and hasCompletedHonors = true are placed in memory.

Step 2

Condition 1: score >= 90 (88 >= 90) evaluates to false. Execution proceeds to the first else if.

Step 3

Condition 2: score >= 80 (88 >= 80) evaluates to true. The block executes, setting letterGrade = 'B'.

Step 4

The remaining else if and else branches are skipped automatically.

Step 5

Compound expression ('B' == 'A' || 'B' == 'B') && true evaluates to true && true = true.

Line-by-Line Explanation

Line 11 — First condition check

if (score >= 90)

Evaluates whether score is 90 or above. Because score is 88, this branch is skipped.

Line 13 — else if branch

} else if (score >= 80) {

Only checked because the preceding if was false. Since 88 >= 80 is true, letterGrade is assigned 'B'.

Line 22 — Compound boolean evaluation

boolean isDeanList = (letterGrade == 'A' || letterGrade == 'B') && hasCompletedHonors;

Parentheses group the OR condition, which is true. True AND true yields true.

Expected Console Output

Score: 88
Assigned Grade: B
Dean's List Eligible: true

AP Exam Tips & Common Traps

Keep these frequent multiple-choice traps in mind:

Dangling Else Ambiguity

An else clause always pairs with the closest preceding unmatched if unless braces {} explicitly enclose it.

Assignment vs Equality Trap

Writing if (x = 5) will cause a compiler error in Java (unless x is boolean). Always use == for comparison.

Short-Circuit Guarding

Use short-circuiting to prevent runtime errors: if (str != null && str.length() > 0) safely avoids a NullPointerException.
