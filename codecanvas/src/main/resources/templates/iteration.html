Iteration

Iteration statements (loops) repeat a block of code while a condition remains true. Understanding for loops, while loops, loop trace tables, off-by-one errors, and nested loops is critical for the AP CS A exam.

Core Concepts & Rules

Essential principles tested on the AP Computer Science A exam:

For Loops

Used when the number of iterations is known in advance. Header syntax: for (init; condition; update).

While Loops

Repeats as long as the condition remains true. Ideal when termination depends on an unknown number of events or user input.

Off-by-One Errors

Occur when loop bounds are slightly incorrect (e.g. using <= instead of <), causing one too many or too few iterations.

Nested Loops

A loop inside another loop. The inner loop completes all its iterations for every single iteration of the outer loop (total iterations = outer × inner).

Example Program

This program demonstrates accumulator patterns, while countdown loops, and nested loop matrix execution.

Complete Java Program

public class IterationDemo {

    public static void main(String[] args) {

        // Accumulator pattern with standard for loop
        int sum = 0;
        for (int i = 1; i <= 5; i++) {
            sum += i;
        }

        // While loop countdown
        int count = 3;
        System.out.print("Countdown: ");
        while (count > 0) {
            System.out.print(count + " ");
            count--;
        }
        System.out.println("Liftoff!");

        // Nested loop printing a 2x3 grid of stars
        System.out.println("Grid:");
        for (int row = 0; row < 2; row++) {
            for (int col = 0; col < 3; col++) {
                System.out.print("* ");
            }
            System.out.println();
        }

        System.out.println("Sum of 1 through 5: " + sum);
    }
}

Understanding the Program Structure

1. The Class Definition

public class IterationDemo defines the enclosing blueprint. In Java, all runnable code resides within a class structure.

2. The Execution Entry Point

public static void main(String[] args) is invoked by the Java Virtual Machine (JVM) to start executing the program.

How Does Java Execute This Program?

Execution trace showing the sequential evaluation and memory state changes:

Step 1

For loop: i runs from 1 through 5. sum accumulates 1 + 2 + 3 + 4 + 5 = 15. At i = 6, the condition 6 <= 5 is false and loop stops.

Step 2

While loop: count starts at 3. Prints 3, 2, 1. When count reaches 0, 0 > 0 is false and loop terminates.

Step 3

Nested loops: Outer loop runs row = 0, 1 (2 rows). For each row, inner loop runs col = 0, 1, 2 (3 stars per row), printing 6 stars in total.

Line-by-Line Explanation

Line 7 — For loop header

for (int i = 1; i <= 5; i++)

1. Initialize i=1. 2. Test i <= 5. 3. Execute body. 4. Increment i++. Repeat steps 2-4.

Line 8 — Accumulator statement

sum += i;

Adds the current value of i into sum on each pass.

Line 14 — While condition

while (count > 0)

Tests before each iteration. The variable count must be updated inside the loop to avoid an infinite loop.

Line 22–26 — Nested loops

for (int row = 0; row < 2; row++) { for (int col = 0; col < 3; col++) {

For row 0, col runs 0, 1, 2. Then row increments to 1, and col runs 0, 1, 2 again.

AP Exam Tips & Common Traps

Keep these frequent multiple-choice traps in mind:

Loop Trace Table

When tracing loops on multiple-choice questions, always draw a quick column table tracking iteration | variable values | output.

Zero vs One Starting Point

for (int i = 0; i < n; i++) executes exactly n times. for (int i = 0; i <= n; i++) executes n + 1 times!

Infinite Loop Guard

Ensure your loop variable is modified toward the termination condition on every path through the loop.
