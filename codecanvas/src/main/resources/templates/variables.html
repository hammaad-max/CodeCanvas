Variables & Data Types

Learn how Java stores information using variables and primitive data types. Understanding these concepts is essential for writing Java programs.

What is a Variable?

A variable is a named location used to store a value in a Java program. The value stored in a variable can be used later in the program.

int age = 18;
double price = 99.99;
boolean student = true;

Java Data Types

int

Stores whole numbers. Example: int age = 18;

double

Stores decimal numbers. Example: double price = 99.5;

boolean

Stores either true or false. Example: boolean active = true;

char

Stores a single character. Example: char grade = 'A';

Example Program

This program creates variables of different data types and then displays their values.

Complete Java Program

public class StudentInfo {

    public static void main(String[] args) {

        String name = "Josh";
        int age = 18;
        double marks = 87.5;
        boolean passed = true;

        System.out.println(name);
        System.out.println(age);
        System.out.println(marks);
        System.out.println(passed);
    }
}

Understanding the Program Structure

Before looking at individual statements, notice the two important parts of every basic Java program:

1. The Class

public class StudentInfo defines a class named StudentInfo. The program's code is written inside the class.

2. The main Method

public static void main(String[] args) is the starting point of the program. Java begins executing the statements inside the main method.

How Does Java Execute This Program?

This program does not contain any loops or conditional statements. Therefore, Java executes the statements inside the main method sequentially, from top to bottom.

Step 1

Java enters the main method.

Step 2

The variables are created and assigned values in order.

Step 3

The first println statement executes.

Step 4

The remaining println statements execute from top to bottom.

Line-by-Line Explanation

Line 1 — Creating the class

public class StudentInfo {

public means the class can be accessed from other parts of the program.

class tells Java that we are defining a class.

StudentInfo is the name of the class.

{ begins the body of the class. Everything belonging to the class is written between this opening brace and its matching closing brace }.

Line 2 — The main method

public static void main(String[] args) {

public allows Java to access the method.

static means Java can run the method without creating an object of the class first.

void means the method does not return a value.

main is the special method where Java starts executing the program.

() contains the information passed into the method.

String[] args represents command-line arguments that can be passed to the program.

{ marks the beginning of the main method's body.

Line 3 — Creating a String variable

String name = "Josh";

String is the data type.

name is the variable name.

= assigns the value on the right to the variable on the left.

"Josh" is the String value. Double quotation marks indicate a String literal.

; marks the end of the statement.

Line 4 — Creating an integer variable

int age = 18;

int stores whole numbers. Here, the variable age stores the value 18.

The statement ends with ;.

Line 5 — Creating a decimal variable

double marks = 87.5;

double is used to store decimal numbers.

The variable marks stores 87.5.

Line 6 — Creating a boolean variable

boolean passed = true;

boolean stores one of two values: true or false.

Here, passed is assigned the value true.

Lines 7–10 — Displaying the values

System.out.println(name);
System.out.println(age);
System.out.println(marks);
System.out.println(passed);

System.out.println() displays a value in the console and moves to the next line.

Java executes these four statements sequentially, from the first println to the last.

Closing braces

    }
}

The first } closes the main method.

The second } closes the StudentInfo class.

Expected Output

Josh
18
87.5
true

The output appears in the same order as the println statements because the statements are executed sequentially.
